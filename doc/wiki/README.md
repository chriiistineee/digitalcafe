# Digital Cafe wiki

This directory tracks the current state of the codebase. Study docs in
`doc/study/` and plan docs in `doc/plan/` record the decisions behind a
feature. This directory records the result.

- [Overview](overview.md): what the app does, the stack, current status
- [Data model](data-model.md): the four models in `core/models.py`
- [Routes](routes.md): every page and route, by file
- [Running the app](running.md): local setup and manual checks
